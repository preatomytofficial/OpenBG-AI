## 🚀 How to Run Locally

### Step 1 — Download the Project
Click the green **"Code"** button on this page → **"Download ZIP"** → Extract the ZIP file

### Step 2 — Open in VS Code
Open VS Code → **File** → **Open Folder** → Select the extracted folder

### Step 3 — Install Python Dependencies
Open the terminal in VS Code (**Terminal → New Terminal**) and run:
```bash
pip install -r requirements.txt
```

### Step 4 — Install Frontend Dependencies
In the same terminal, run:
```bash
npm install
```

### Step 5 — Start the App
Run the Python backend:
```bash
python app.py
```
Then in a new terminal, run the React frontend:
```bash
npm start
```

### Step 6 — Open in Browser
Go to 👉 `http://localhost:3000`

Upload your image and enjoy background removal! 🎉
